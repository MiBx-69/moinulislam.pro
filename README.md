## Featured project

**MiBx Dispatch — E-commerce Operations ERP**

A real-world operational platform connecting Shopify order workflows with courier dispatch, delivery states, returns, finance tracking, fraud checks, SMS notifications, reporting and live KPIs. The project is designed around reducing repetitive manual work and giving e-commerce teams one operational view. The portfolio now presents this as a visual case study with desktop and mobile interface galleries.
